## 先弄清楚"搬瓦工美国VPS"到底指什么

需要分清的是，搬瓦工的"美国 VPS"实际上分两类产品线：

## 美国机房有哪些，分别走什么线路

搬瓦工在美国有多个机房，不同机房线路质量差异很大，选错机房可能花更多钱反而体验更差。下面是几个主要美国机房的情况。

**DC2（洛杉矶 QNET）**：普通 KVM 套餐可选，走 163 线路，晚高峰对中国方向丢包较多，适合纯美国本地或欧洲方向使用。

**DC8（洛杉矶 ZNET）**：同样属于普通 KVM 套餐可选范围，CN2 GT 退场后线路质量一般，不建议面向中国大陆用户建站使用。

**DC6（洛杉矶 CN2 GIA-E）**：CN2 GIA-E 套餐专用，电信回程走 CN2 GIA，移动走 CMIN2，联通走 AS10099，是搬瓦工对中国大陆方向质量最好的美国机房之一。

**DC9（洛杉矶 CN2 GIA-E）**：CN2 GIA-E 套餐可选，AMD EPYC + NVMe 服务器，网络容量比 DC6 更大，三网优化与 DC6 一致，目前是搬瓦工美国机房的旗舰位置。

**FMT（弗里蒙特）**：普通 KVM 套餐可选，位于美国西海岸，对中国方向线路普通，适合美国本土业务。

**USNJ（新泽西）/ USNY（纽约）**：普通 KVM 套餐可选，美国东海岸机房，对中国方向延迟较高（180ms 以上），适合面向欧洲或美国东部用户。

**EUNL_2/EUNL_3/EUNL_9（荷兰阿姆斯特丹）**：EUNL_9 是 CN2 GIA-E 套餐可选机房，三网回程走 CN2 GIA + AS9929 + CMIN2，联通用户友好；EUNL_2/EUNL_3 是普通 KVM 套餐可选机房，走欧洲本地线路。

简单说：要美国机房又要对中国大陆线路好，DC6 和 DC9 是唯一选择，两者都属于 CN2 GIA-E 套餐。普通 KVM 套餐的几个美国机房对中国方向都没有专门优化。

## 一键换机房：KiwiVM面板里的免费迁移功能

搬瓦工的机房迁移功能是很多人选它的一个重要原因。不需要提工单，也不用等客服，整个操作在 KiwiVM 控制面板里就能完成。

操作步骤：

1. 登录搬瓦工后台，进入 My Services，找到要迁移的 VPS，点击 KiwiVM Control Panel。
2. 在左侧菜单找到 "Migrate to another DC" 或 "Data Center Migration"。
3. 页面会显示当前所在机房和可选迁移目标列表。
4. 选择目标机房，点击 "Confirm on next step"。
5. 系统会提示迁移时间和注意事项，确认后开始迁移，整个过程通常几分钟到十几分钟完成。

迁移是免费的，VPS 数据会自动搬过去，不需要重装系统。但有几个限制需要注意：

## 几个常见问题

**搬瓦工美国 VPS 被墙了怎么办？**
搬瓦工的 IP 会被封，尤其是用于科学上网的 IP。普通 KVM 套餐被封后只能通过迁移机房换 IP，但迁移不一定能避开封禁。CN2 GIA-E 套餐被封概率相对低一些，但也不是绝对安全。SLA 套餐支持每两周免费换一次 IP，对 IP 稳定性要求高的用户更友好。

搬瓦工的优势在于 CN2 GIA 线路和对中国大陆方向的优化，价格也比 Vultr/Linode 同配置便宜不少。但搬瓦工是自管理服务，技术支持和文档完善度不如 Vultr/Linode。如果业务主要面向欧美用户，Vultr/Linode 的全球节点和按小时计费更灵活；如果面向中国大陆用户，搬瓦工 CN2 GIA-E 性价比明显更高。

支持支付宝、PayPal、信用卡、银联、BitPay 等。中国用户最方便的是支付宝，直接扫码付款，开通即时。

**新购的 VPS 怎么登录？**
付款后会收到邮件，里面包含 KiwiVM 面板登录地址、root 密码、VPS IP 等信息。登录 KiwiVM 面板后可以重装系统、查看流量、迁移机房、设置 rDNS 等。SSH 登录使用 root 账户和邮件中的初始密码，建议首次登录后立即修改。
